使用说明

📚 开局库

左侧按分类浏览经典开局。点击开局展开变例，点击变例即会把棋谱摆到棋盘上；用 ◀ ▶ 逐步研究，右侧「讲解」面板会同步显示每一步的中文说明。

🎯 训练

选择训练范围与执棋方后开始训练：程序扮演对手走棋，轮到你时必须走出开局书上的正确着法。走错会立刻标出正确着法并给出提示，可以重试。

🔁 复习

系统用间隔重复安排复习：答对的线路间隔逐渐拉长（1 → 3 → 7 → 16 → 35 天），答错的线路会自动回到错题本并很快再次出现。

⌨️ 快捷键

  • ← / →：上一步 / 下一步
  • ↑ / ↓：回到起始 / 跳到末尾
  • F：翻转棋盘　Space：自动播放
  • H：提示　Esc：关闭弹窗
  • 棋盘上拖动或点击走子；右键拖动画箭头，右键单击清除箭头

ℹ️ 说明

本软件内置自研规则引擎（通过全部标准 perft 测试），不依赖任何联网服务；所有进度保存在本机浏览器中。

安装后可从开始菜单 / 桌面直接打开，独立窗口运行，并且支持离线使用。
